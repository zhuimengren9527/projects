# 算法复杂度（大 O 表示法）名词解释

### 1. 时间复杂度 (Time Complexity)
* **简单理解**：随着数据量（n）的增加，代码运行时间增长得有多快。
* **衡量标准**：不看具体的秒数，只看“增长级”。

### 2. O(1) —— 常数级（极速）
* **特征**：不管数据有多少，速度永远一样快。
* **例子**：通过索引直接拿数据。比如：`counts[2]`。
* **评价**：这是算法的最高境界。

### 3. O(n) —— 线性级（优秀）
* **特征**：数据增加一倍，时间也增加一倍。
* **例子**：一个简单的 `for` 循环。比如：把字符串从头到尾扫一遍。
* **评价**：非常稳。

### 4. O(n²) —— 平方级（危险）
* **特征**：数据增加一倍，时间增加四倍！
* **例子**：双重嵌套循环。比如：在一个 `for` 循环里又写了一个 `for` 循环。
* **评价**：数据量大时会卡死，尽量避免。
