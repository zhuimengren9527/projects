# Git 环境配置与终端命令复盘笔记

## 1. 常用命令速查表
这些是在 VS Code 终端（PowerShell）中频繁使用的“基建”命令：

| 命令        | 全称/含义              | 动作描述                   | 相当于鼠标操作         |
| :---------- | :--------------------- | :------------------------- | :--------------------- |
| **`mkdir`** | **M**ake **Dir**ectory | **创建**文件夹             | 右键 -> 新建文件夹     |
| **`mv`**    | **M**o**v**e           | **移动**或**重命名**文件   | 剪切 + 粘贴            |
| **`type`**  | **Type** (内容)        | 在终端直接**显示**文件内容 | 双击打开文件看一眼就关 |
| **`code`**  | VS **Code**            | 调用 **VS Code** 打开文件  | 右键 -> 通过 Code 打开 |
| **`ls`**    | **L**i**s**t           | **列出**目录下的所有文件   | 打开文件夹查看图标     |

---

## 2. 命令的语法逻辑
命令后面的长路径（如 `C:\Users\ryd19\.ssh\...`）就是命令的**“操作目标”**。

**逻辑公式：** `[动词/命令] + [起点/目标路径] + [终点路径(可选)]`

* **例子（搬家）：**
  `mv C:\projects\yes C:\Users\ryd19\.ssh\id_ed25519`
  * **动词**：`mv` (搬家)
  * **宾语**：`C:\projects\yes` (把这个箱子)
  * **目的地**：`C:\Users\ryd19\.ssh\id_ed25519` (搬到那个房间并改名)

---

## 3. 实战操作复盘
记录本次在私人电脑配置 SSH 时的关键步骤：

### 第一步：创建标准存放目录
`mkdir C:\Users\ryd19\.ssh`
* **意义**：在用户目录下建立 Git 默认寻找钥匙的“新房间”。

### 第二步：正确归位并重命名
`mv C:\projects\yes C:\Users\ryd19\.ssh\id_ed25519`
`mv C:\projects\yes.pub C:\Users\ryd19\.ssh\id_ed25519.pub`
* **意义**：将误存在项目目录下的钥匙搬回“老家”，并改成 Git 能识别的标准名字。

### 第三步：查看并提取公钥
`type C:\Users\ryd19\.ssh\id_ed25519.pub`
* **意义**：把公钥内容“打”在屏幕上，方便复制后贴到 GitHub 的 Settings 中。

### 第四步：编辑器协助
`code C:\Users\ryd19\.ssh\id_ed25519.pub`
* **意义**：当内容太长不方便在终端复制时，直接调出 VS Code 界面查看。

---

## 4. 核心提示
* **SSH 优势**：配置一次，终身免密。不依赖代理，比 HTTPS 更稳更快。
* **操作习惯**：尽量使用 `Tab` 键自动补全路径，避免手动输入长路径出错。
