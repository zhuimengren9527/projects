【进入内存】 1. FROM     : 锁定并载入目标物理表
【行级清洗】 2. WHERE    : 逐行扫描，把不符合条件的行当场物理抹杀（此时没有堆，没有别名）
【破行成堆】 3. GROUP BY : 斩断行流，将幸存的行按照字段物理分堆（组）
【堆级审查】 4. HAVING   : 拿着聚合函数大喇叭，对整堆特征做资格审查（算完临时值就扔）
【册封装车】 5. SELECT   : 挑出字段，正式执行最终计算，并册封【别名（标签）】
【降维排序】 6. ORDER BY : 拿着 SELECT 刚贴好的标签，对最终的堆结果进行排序
【末路斩断】 7. LIMIT    : 在排好序的终点线上架起断头台，只截取前 N 条数据输出

HAVING 确实在计算 AVG，但它计算 AVG 的目的，仅仅是为了给这一个堆做“生存资格审查”，算完就随手扔了；只有到了 SELECT，这个值才被真正装进最终的表格里，赋予它物理生命（别名）。
